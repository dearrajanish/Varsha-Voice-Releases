# 🚀 Varsha Voice - Android Releases

Welcome to the official repository for **Varsha Voice** updates. This repository is strictly used for hosting the latest secure OTA (Over-The-Air) APK releases for the app.

### 🎙️ Key Features

*   **Real-Time AI Voice Conversion:** Instantly convert male voice inputs into a highly realistic female voice using advanced AI models.
*   **Hybrid Architecture:** Seamlessly toggle between high-speed Cloud API processing and secure Offline (Local) processing.
*   **Custom API Integration:** Users can securely enter and save their own Hugging Face API keys locally for complete privacy and control.
*   **Seamless In-App Updates:** Built-in OTA updater using Android's native DownloadManager to keep the app up to date automatically.

### 📥 How to Download

If you are a beta tester or a whitelisted user, your app will automatically notify you when a new update is available here. You can also manually download the latest `app-release.apk` from the [Releases Tab](https://github.com/dearrajanish/Varsha-Voice-Releases/releases).
